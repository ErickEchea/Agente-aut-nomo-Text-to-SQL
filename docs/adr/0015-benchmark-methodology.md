# ADR-0015 — Benchmark methodology

- Status: Accepted
- Date: 2026-11-20

## Decision
- **Golden set**: `bench/golden/*.yaml`, ≥ 120 Spanish questions over the retail DB, tagged
  `easy | medium | hard | ambiguous`, each with `gold_sql` and a frozen `expected_result` (generated by running
  `gold_sql` and committed, so a drift in data or gold SQL is caught by a test). `ambiguous` items carry
  `expected_behavior: clarify` and the accepted option set instead of a result.
- **Execution accuracy** (primary): predicted and expected result sets are compared as multisets of rows after
  normalization (decimal rounding to 2 places, timestamps to ISO, NULL handling, column order ignored by matching
  column value-vectors); order is compared only when the gold SQL's outermost query has `ORDER BY` and the question
  asks for a ranking. Extra columns in the prediction are tolerated if the gold columns are a subset.
- For ambiguous items, success = the agent asks for clarification (and does not execute).
- **Secondary metrics**: p50/p95 end-to-end latency, per-node latency, error rate, recovery rate (succeeded after
  ≥ 1 repair / failed first attempt), tokens per question, grounding-failure rate, retrieval recall@5.
- **Runs**: `make bench MODELS="qwen2.5-coder:7b qwen3:8b …"` executes the golden set through the real graph
  (same code path as the API), writes JSON to `bench/results/`, renders `docs/benchmark.md`, and stores results
  in `benchmark_runs/benchmark_results` for the Benchmark page. Temperature 0 and fixed seed where the model
  supports it; 1 warm-up question excluded from latency.
- **CI subset**: ~15 questions on the CPU model; the job asserts the pipeline completes and accuracy does not drop
  below a threshold calibrated in Phase 6 (documented with the baseline it was calibrated against).
- Leakage control: verified few-shot examples used at inference are disjoint from golden-set questions (checked by
  a test using normalized-text and embedding similarity).

## Consequences
- The default model is a data-driven decision recorded in a superseding ADR.
